# HiT Myanmar — HTML Practice Workbook

A beginner-friendly HTML practice workbook for **HiT Myanmar Software Developer Career Camp** students.

This workbook is designed to help students move beyond only watching prerecorded lessons.

Students will practice each topic through:

- **Quiz** — Check understanding
- **Exercise** — Practice individual concepts
- **Challenge** — Apply what was learned by writing code

---

# Learning Flow

For each section:

```text
Watch Lessons
     ↓
Quiz
     ↓
Exercises
     ↓
Challenge
     ↓
Continue to Next Lessons
```

The goal is simple:

> **Learn → Practice → Build**

Students are encouraged to try each exercise and challenge independently before asking for help.

# How to Use This Workbook

For every section:

### 1. Complete the Lessons

Watch the assigned prerecorded lessons first.

### 2. Take the Quiz

Complete the quiz without immediately checking course materials.

Use it to identify topics that you may need to review.

### 3. Complete the Exercises

Exercises are short practice tasks.

You may review your lesson notes if necessary, but try solving the problem yourself first.

### 4. Complete the Challenge

Challenges require you to write more code independently.

Read the requirements carefully and build the solution yourself.

There may be more than one correct way to complete a challenge.

---

# Important Rules

- Try the problem yourself before asking for help.
- Do not copy another student's complete solution.
- Read error messages and check your code carefully.
- Use your course lessons and notes when necessary.
- Focus on understanding the code, not only getting the expected result.
- Ask questions when you cannot solve a problem after trying.
- Be prepared to explain the code you write.
