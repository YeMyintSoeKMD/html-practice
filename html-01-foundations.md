# 3. Challenges

## Challenge 1 — About Me Page

Create a simple HTML page called **About Me**.

Your page must contain:

- A proper HTML document structure
- Page title: `About Me`
- One `<h1>` containing your name
- One `<h2>` containing `About Me`
- At least two paragraphs about yourself
- At least one text-formatting element
- At least one HTML attribute
- At least one HTML comment

### Rules

Use only the concepts covered in **Lessons 1–14**.

Do not use:

- CSS
- Images
- Links
- Tables
- Forms

Focus only on HTML foundations.

---

## Challenge 2 — My Developer Journey

Create an HTML page called **My Developer Journey**.

Your page should contain these sections:

```text
My Developer Journey

About Me

Why I Learn Web Development

My Goal
```

Write your own content for each section.

### Requirements

Your page must include:

- A proper HTML document structure
- One `<h1>`
- At least two `<h2>` elements
- At least three paragraphs
- At least two text-formatting elements
- At least one properly nested element
- At least two HTML attributes
- At least one HTML comment

Do not copy a complete solution.

Build the page yourself using what you learned from Lessons 1–14.
